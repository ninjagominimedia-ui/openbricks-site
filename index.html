Six versions of every card

Same Kai, very different value

Packs can hand you a special version instead of the normal card. Each one is numbered, and once its print run is gone nobody can pull it again.

Ghost cards only drop during a real full moon. Type !moon in Discord to see when the next one is.

What's in it

More than catching cards

Everything runs on one currency, OBCoins, and one collection, so what you do in one part counts everywhere else.

  • CatchingCards spawn in the channel you pick. Type the name before anyone else.
  • Packs10 cards per pack. One in five packs has a guaranteed Full Art.
  • BattlesPick a 3-card deck and fight. Fire beats Ice, Water beats Fire. Monthly ranked seasons with coin prizes.
  • SleevesFrames for !flex. The Season Champion sleeve only goes to the #1 battler.
  • EconomyA bank vault, a rotating shop, loans, trading and a 200k Upgrade Token that turns a normal card into Holo.
  • GamesEpisode, quote and minifigure guessers, quizzes, blackjack, mines and more.
  • Server toolsWelcome messages, logs, starboard and moderation. Set them up on the dashboard.
